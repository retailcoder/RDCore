# RDC00422: Missing annotation argument

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation has fewer arguments than its parameters require.

The message names the parameter that has no argument.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An annotation with no argument for a required parameter.|`'@Folder`|Write the argument: `'@Folder "Tools"`.|
|A list annotation with an empty list.|`'@Ignore`|Name at least one diagnostic code: `'@Ignore RDC00101`.|
