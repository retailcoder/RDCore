# VBR00402: Must close or hide topmost modal form first

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A Visual Basic 6.0 form is hidden while a modal form is displayed, and it is not the topmost modal form.

Visual Basic run-time error 402; the numeric portion of the code is the error's number. While a modal form is displayed, only the topmost modal form can be hidden, which ends its `Show` (measured in VB6).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A form beneath the modal form is hidden.|`Form1.Hide`, while `Form2` is shown with `vbModal`|Hide or unload the modal form first.|
|A modal form is hidden while another modal form is shown over it.|`Form2.Hide`, while `Form3` is shown modal over `Form2`|Hide or unload `Form3` first.|
