# RDC00420: Duplicated annotation

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation that can be written once is written again for the same module, procedure or variable.

The diagnostic marks each one after the first. Annotations that list things, such as `'@Ignore`, can be written more than once.

This diagnostic is raised for the core's annotations; an extension checks the annotations it declares.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The same annotation twice in the declarations section.|`'@ModuleDescription "One."` then `'@ModuleDescription "Two."`|Keep one.|
|The same annotation twice above one procedure.|`'@Description "One."` then `'@Description "Two."` above a `Sub`|Keep one.|
