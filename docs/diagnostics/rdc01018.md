# RDC01018: Keyword used as a member name

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `KeywordUsedAsMemberNameAnalyzer`

An Enum member or a member of a user-defined type is named with a keyword of the language.

A member of a user-defined type may be named with a keyword, such as `Next` or `Loop`
([**MS-VBAL §5.2.3.3** User Defined Type Declarations](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/a5fe374b-eddf-4808-9e73-477914940dba)).
An Enum member may be, when its name is written in brackets, such as `[Select]`: a name in brackets is a foreign name (**MS-VBAL §3.3.5.3**).
Both compile. Code that uses such a member reads like the keyword, and an Enum member must be written in brackets wherever it is used without its Enum.

A keyword is a `reserved-identifier`
([**MS-VBAL §3.3.5.2** Reserved Identifiers and IDENTIFIER](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/e1ac8be4-9b8d-4a4c-a1a4-6cc4ecba6b95)).
A name that MS-VBA refuses or that differs from MS-VBAL, such as an Enum member named `Date`, is reported by
[RDC11033](rdc11033.md) or [RDC11034](rdc11034.md) instead.

The finding is the name of the member.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A member of a user-defined type named with a keyword.|`Type Node`<br>`    Next As Long`<br>`End Type`|Rename the member: `NextIndex`.|
|An Enum member named with a keyword in brackets.|`Enum Clause`<br>`    [Select] = 1`<br>`End Enum`|Rename the member: `SelectClause`.|

## Quick fix

The diagnostic comes with a quick fix that renames the member, to the name you give, where it is declared and wherever it is used.
