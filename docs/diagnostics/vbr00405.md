# VBR00405: Unable to show modal form within this context

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A Visual Basic 6.0 form that is modal already is shown modal again.

Visual Basic run-time error 405; the numeric portion of the code is the error's number. A modal `Show` of a form that is shown modeless, or of one beneath the modal form, turns it modal; a modal `Show` of the modal form itself fails (measured in VB6).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The modal form is shown modal in its own code.|`Me.Show vbModal` in a handler of `Form2`, while it is modal|Leave the form as it is: it is modal already.|
