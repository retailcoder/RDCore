# RDC01004: Empty code block

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `EmptyCodeBlockAnalyzer`

An `Else`, `Case`, `Do`, `For`, `For Each` or `While` block has no statement.

Comments, line labels and `Dim`, `Static` and `Const` declarations are no statements: a block that holds only those is empty. An empty block is often unfinished code.

- An empty `Else` does nothing, and can be removed.
- An empty `Case` does nothing for its values, and keeps them from the `Case` clauses after it: a `Case` does not fall through to the next one
  ([**MS-VBAL §5.4.2.10** Select Case Statement](../specs/rd-vbal.5.4.2.10.select-case-statement.md)).
- An empty loop still evaluates its condition, its bounds or its collection, and a `For` loop leaves its counter past the end
  ([**MS-VBAL §5.4.2.3** For Statement](../specs/rd-vbal.5.4.2.3.for-statement.md)).

An empty `Case Else` is not reported: it states that the other values are left alone. An empty `If` or `ElseIf` branch is [RDC01003](rdc01003.md).

The finding is the header of the block, its keyword and what it states.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An `Else` with no statement.|`If foo Then`<br>`    DoSomething`<br>`Else`<br>`End If`|Remove the `Else`.|
|A `Case` with no statement.|`Case 0`<br>`Case Is > 0`<br>`    Debug.Print foo`|Write what it does, or say in a comment why its values do nothing.|
|A `Do` loop with no statement.|`Do`<br>`Loop While foo < 100`|Remove the loop, or write its body.|
|A `For` or `For Each` loop with no statement.|`For i = 0 To foo`<br>`Next`|Remove the loop, or write its body. Assign the counter if its last value is what the loop is for.|
|A `While` loop with no statement.|`While foo < 100`<br>`Wend`|Remove the loop, or write its body.|
