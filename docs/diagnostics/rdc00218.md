# RDC00218: IsMissing of a Variant that is not Optional

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IsMissingOfAVariantThatIsNotOptionalAnalyzer`

`IsMissing` is given a required `Variant` parameter, or a `Variant` variable, so it does not tell whether an argument was omitted.

`IsMissing` returns `True` when its argument holds the Missing value ([**MS-VBAL §6.1.2.7.1.6**](../specs/rd-vbal.6.1.2.7.information.md)). Only an
`Optional` parameter whose argument was omitted is given that value by the call. A required `Variant` parameter holds it only when a caller passes on such a
parameter of its own, and a `Variant` variable only when the code assigns one to it. Code that tests `IsMissing` of either looks like it handles an omitted
argument of the procedure, which cannot be omitted.

`IsMissing` of an `Optional` `Variant` parameter with no default value is not reported. `IsMissing` of a name that can never hold the Missing value is
[RDC00207](rdc00207.md).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A required `Variant` parameter.|`Sub Report(Title As Variant)` … `If IsMissing(Title) Then`|Declare it `Optional` (`Optional Title As Variant`), or remove the test.|
|A `Variant` variable.|`Dim Title As Variant` … `If IsMissing(Title) Then`|Test the `Optional` parameter the value came from.|
