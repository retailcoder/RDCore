# RDC00421: Annotation in an incompatible kind of module

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation is written in a kind of module it does not apply to.

Some annotations apply to some kinds of module only: `'@Interface` and `'@PredeclaredId` to a class module, `'@ExcelHotkey` to a standard module. In
another kind of module the annotation is not read.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A class module annotation in a standard module.|`'@Interface` above `Module Helpers`|Remove it, or make the module a class module.|
|A standard module annotation in a class module.|`'@ExcelHotkey "A"` above a procedure of a class|Move the procedure to a standard module.|
