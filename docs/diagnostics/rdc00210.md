# RDC00210: Stop statement

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `StopStatementAnalyzer`

A procedure holds a `Stop` statement.

`Stop` suspends the program where it is, as a breakpoint does ([**MS-VBAL §5.4.2.11** Stop Statement](../specs/rd-vbal.5.4.2.11.stop-statement.md)).
It is a debugging aid: left in code that is not being debugged, it interrupts the user of the program.

The finding is the `Stop` keyword.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `Stop` statement.|`Sub Foo()`<br>`    Stop`<br>`End Sub`|Remove it once the code is debugged. A breakpoint of the editor stops at the same place, and is not part of the code.|

## Quick fix

A `Stop` on a line of its own comes with a quick fix, *Remove the Stop: the program no longer breaks here*. It removes the line, with a comment on it.
The program no longer suspends there. It is not offered when the `Stop` shares its line with a label or another statement.
