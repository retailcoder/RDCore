# RDC11030: Jump into a For loop

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `JumpIntoForLoopAnalyzer`

A `GoTo` or a `Resume` jumps to a label inside a `For` or a `For Each` loop, from outside it. The `For` statement that opens the loop doesn't run.

The specification says that the loop's `Next` then raises run-time error 92 (For loop not initialized) (**MS-VBAL §5.4.2.3**). In Excel, it raises 92 for a
`For Each` loop, and for a `For` loop whose counter is declared `Variant`. A `For` loop whose counter has any other type runs: its `Next` steps the
counter as if the loop ended at 0, by 1, or by 0 when the loop has a `Step` (recorded in Excel). A loop that already ran in the same call keeps the end and
the step it had.

```vba
Dim i As Long
GoTo Inside
For i = 1 To 3
Inside:
    Debug.Print i    ' prints 0
Next i               ' i is 1, past the end of 0: the loop ends
```

RD-VBA does as MS-VBA does. This warning stands for what the specification says.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A `GoTo` to a label inside a loop, from outside it.|`GoTo Inside`, with `Inside:` in the body of a `For`|Jump to a label before the `For`, or move the code out of the loop.|
|A `Resume` to a label inside a loop, from a handler outside it.|`Resume Retry`, with `Retry:` in the body of a `For`|Resume at a label before the `For`.|
