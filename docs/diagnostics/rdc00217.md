# RDC00217: Function result always discarded

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `FunctionReturnValueAlwaysDiscardedAnalyzer`

A `Friend` `Function` is called only as a statement: every call in the project discards the value it returns.

A call statement can call a `Function` as well as a `Sub`
([**MS-VBAL §5.4.2.1** Call Statement](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/f7c864a8-8fce-49dc-8347-30dc749d6576)).
When no caller uses the value, the function works as a `Sub`, and the code that assigns its return value can be removed.

Only a `Friend` function is reported: its calls are all in the project, and the analysis counts them. Another project can call a `Public` function, and a
`Private` one can be called through a string that holds its name, which the analysis does not count. A function no code calls is not reported here.

The finding is the declaration of the function. Each call is also reported as [`RDC00216`](rdc00216.md).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|No caller needs the value.|`Friend Function Add(ByVal n As Long) As Long`, called only as `c.Add 1`|Make it a `Sub`.|
|A caller should have checked the value.|`Friend Function Save() As Boolean`, called only as `doc.Save`|Use the value where it matters: `If Not doc.Save Then ...`.|
