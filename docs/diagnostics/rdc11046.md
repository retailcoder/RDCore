# RDC11046: Let through a Variant property or function

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `LetThroughAVariantGetOrFunctionAnalyzer`

A `Let` statement assigns a value to a `Property Get` that has no `Property Let`, or to a function, declared `Variant`, outside its own body.

[**MS-VBAL §5.4.3.8**](https://learn.microsoft.com/en-us/openspecs/microsoft_general_purpose_programming_languages/ms-vbal/ce2a98d4-2625-4cb7-982c-5c58e568cd18)
raises error 451 for the property and error 450 for the function. RD-VBA does what MS-VBA does (observed in Excel): it calls the member, and assigns the value to
the default member of the object it returns. When it returns no object, the statement raises error 424.

```vb
' Holder: Property Get Item() As Variant, no Property Let
h.Item = 5    ' MS-VBAL: error 451; RD-VBA and MS-VBA: Item's object's default member is 5
```

## How it is raised

|Situation|Example|What to do|
|---|---|---|
|The value is meant for the object the member returns.|`h.Item = 5`, where `Item` returns a `Range`|Name the member of that object: `h.Item.Value = 5`.|
|The value is meant for the member itself.|`h.Item = 5`, where `Item` returns a number|Give the class a `Property Let Item`.|
