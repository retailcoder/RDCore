# RDC00412: Control used outside its form

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `PublicControlFieldAccessAnalyzer`

Code in another module uses a control of a form.

Each control of a form is a public member of the form's class, so any module can read it and change it (`UserForm1.TextBox1.Text = ""`). The form then
does not control its own state: the code that fills, validates and reads its controls is spread over the modules that use them. A form usually exposes
what its callers need as properties or procedures of its own, and keeps its controls to its own code.

The finding is the expression that names the control. A control reached through a variable of the form's class (`f.TextBox1`) is reported the same way.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A control of a form, used in another module.|`UserForm1.TextBox1.Text = "a"` in `Module1`|Add a property or a procedure to the form (`UserForm1.UserName = "a"`) that sets the control in the form's own code.|
