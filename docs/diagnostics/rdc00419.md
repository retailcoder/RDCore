# RDC00419: Unrecognized annotation

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation comment names an annotation that nothing installed on this platform declares.

The core declares some annotations, such as `'@Description` and `'@Folder`; each extension declares its own. An annotation is unrecognized when its
name is misspelled, or when it belongs to an extension that is not installed or not allowed to load on this platform. An unrecognized annotation has no
effect.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The name is misspelled.|`'@Descripton "Does it."`|Correct the name.|
|The annotation belongs to an extension that is not installed.|`'@Route "/orders"`, where no installed extension declares `Route`|Install the extension, or remove the annotation.|
|The extension is installed, but the platform's settings do not allow it to load.|An annotation of an extension that is not in the list of allowed extensions|Allow the extension, or remove the annotation.|
