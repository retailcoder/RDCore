# VBR00092: For loop not initialized

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](../api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A loop is run from the middle, or a `For Each` array was never dimensioned.

MS-VBA run-time error 92; the numeric portion of the code is the error's number. This code is raised by `ProcedureExecutor`.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A loop is run from the middle, or a `For Each` array was never dimensioned.|`GoTo` into a `For Each` loop, or into a `For` loop whose counter is a `Variant`|Enter a loop through its opener.|

A `For` loop whose counter has any other type, run from the middle, doesn't raise this error: it runs as if it ended at 0, as it does in MS-VBA
([**RDC11030**](rdc11030.md)).
