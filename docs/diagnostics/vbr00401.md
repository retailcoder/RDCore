# VBR00401: Can't show non-modal form when modal form is displayed

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A Visual Basic 6.0 form is shown modeless while a modal form is displayed.

Visual Basic run-time error 401; the numeric portion of the code is the error's number. While a form shown with `vbModal` is displayed, a modeless `Show` of any form fails: a hidden form, a form that is shown already, and the modal form itself (measured in VB6).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A form is shown modeless while a modal form is displayed.|`Form3.Show`, while `Form2` is shown with `vbModal`|Show it modal (`Form3.Show vbModal`), or show it after the modal form is hidden or unloaded.|
|The modal form is shown modeless in its own code.|`Me.Show` in a handler of `Form2`, while it is modal|Leave the form as it is: it is shown already.|
