# RDC00404: Invalid annotation

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation is written where it annotates nothing it applies to.

Each annotation annotates a module, a procedure or a variable
([**RD-VBAL §3.0.1.1** Comment Annotations Syntax](../specs/rd-vbal.3.0.1.token-semantics.md#3011-comment-annotations-syntax)).
A module annotation is written in the module's declarations section, or above a block's header. A procedure or variable annotation is written on the
lines right above the declaration. An annotation written anywhere else is not read.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A module annotation above a procedure that follows another one.|`'@Folder "Tools"` above the second `Sub`|Move it to the declarations section.|
|A procedure annotation in the declarations section, with no procedure right below it.|`'@Obsolete` above `Option Explicit`|Move it right above the procedure.|
|An annotation in a procedure's body.|`'@Description "Does it."` between `Sub` and `End Sub`|Move it above the procedure.|
