# RDC00201: Integer data type declaration

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `IntegerDataTypeAnalyzer`

A declaration has an `As Integer` clause.

An `Integer` is a 16-bit signed type that overflows at 32,767, where a `Long` holds more than two billion
(**MS-VBAL §2.1** Data Values and Value Types; [**RD-VBAL §2.4.1** Intrinsic Types](../specs/rd-vbal.2.4.1.intrinsic-types.md)). The diagnostic is an opinion of the analyzer and not a condition of the language: both are legal VBA.

A `Declare` statement is not looked into: the types it states are the ones the external procedure takes, and are not the declaring module's to choose. Neither are
the parameters and the return type of a procedure that implements a member of an interface (`IShape_Area`) or handles an event (`Button_Click`): the interface or
the event states them, and the procedure must state them the same way. The variables of its body are reported. A user-defined type that is read from or written
to a file in a format that has 16-bit fields is a reason to keep an `Integer`; so is a procedure that must be called through a signature that states it.

That a declaration states the type is a fact of the way it is written: the analyzer reads it off the syntax tree, and reports the `As` clause.

## Fixing it

The code action changes the type to `Long`, which changes what the declaration holds: that is what it is for, and its title says so. It is offered where no other
code has to change with it:

- the variable or the parameter is never passed as an argument, which a `ByRef` parameter `As Integer` takes only as an `Integer`;
- a parameter is `ByVal`, so that any argument it is given still converts to its type;
- the procedure is not a property whose other procedures state the type too, nor a `Public` member of a class, which a class that implements it states as well.

A field of a user-defined type and a `ReDim` are not changed.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A variable, a parameter, a return type or a field of a user-defined type is declared `As Integer` (or `As VBA.Integer`).|`Dim count As Integer`|Declare it `As Long`, unless a 16-bit value is what is needed.|
