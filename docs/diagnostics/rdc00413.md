# RDC00413: Module variable used in one procedure

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `MoveFieldCloserToUsageAnalyzer`

A `Private` variable of the module is used in one procedure only. It can be declared in that procedure, where a reader sees it with the code that uses it.

A variable of the module keeps its value from one call to the next, and a local does not. When the procedure counts on that, declare the local `Static`.

A `WithEvents` variable is not reported: the procedures that handle its events use it too.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The procedure sets the variable before it reads it.|`Private mTotal As Long`, used only in `Sum`, which starts with `mTotal = 0`|Declare it in `Sum`: `Dim total As Long`.|
|The procedure keeps the value between calls.|`Private mCalls As Long`, used only in `Log`, as `mCalls = mCalls + 1`|Declare it `Static` in `Log`: `Static calls As Long`.|
