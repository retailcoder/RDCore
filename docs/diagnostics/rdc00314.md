# RDC00314: Redundant ByRef modifier

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `RedundantByRefModifierAnalyzer`

A parameter states `ByRef`.

A parameter that states neither `ByRef` nor `ByVal` is passed by reference
([**MS-VBAL §5.3.1.5** Parameter Lists](../specs/rd-vbal.5.3.1.5.parameter-lists.md)), so `ByRef` changes nothing.

The diagnostic is reported only when the `Diagnostics.ByRefModifier` setting is `Implicit`. With the default, `Explicit`, `ByRef` is written, and a parameter
that states neither is [RDC00104](rdc00104.md) instead. Both are legal VBA.

These parameters are not reported:

- a parameter of a `Declare`, which states how each argument goes to the library;
- a parameter of a procedure that implements an interface member or handles an event, which repeats the declaration it matches;
- the value parameter of a property `Let` or `Set`, whose `ByRef` is [RDC00205](rdc00205.md).

The finding is the parameter.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A parameter that states `ByRef`, under the `Implicit` convention.|`Public Sub DoSomething(ByRef foo As Long)`|Remove `ByRef`.|
