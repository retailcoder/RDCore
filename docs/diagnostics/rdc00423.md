# RDC00423: Superfluous annotation argument

**Severity:** Warning &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `AnnotationDeclarationsAnalyzer`

An annotation has more arguments than its parameters take.

The arguments after the last parameter are not read. The diagnostic marks them.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|An argument after the last parameter.|`'@Folder "A", "B"`|Remove it, or join the two: `'@Folder "A.B"`.|
|An argument of an annotation that takes none.|`'@NoIndent "A"`|Remove it.|
