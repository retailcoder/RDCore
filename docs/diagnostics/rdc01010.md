# RDC01010: Empty module

**Severity:** Information &nbsp;·&nbsp; **Family:** `RDC` (Rubberduck Core analyzers) &nbsp;·&nbsp;
**Raised by:** `EmptyModuleAnalyzer`

A module declares nothing: no variable, constant, procedure, `Declare`, `Enum`, `Type` or `Event`, and no `Implements`
([**MS-VBAL §5.2** Module Declaration Section Structure](../specs/rd-vbal.5.2.module-declaration-section-structure.md)).

Its options, attributes, `Def`*Type* statements and comments declare nothing. A module that declares nothing does nothing in the project, and can be removed.

A form is not reported: its designer is part of it, whether its code declares anything or not. A document module, the code of a host's document, is not reported either.

The finding is the first line of the module.

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|A standard or class module with only options and comments.|`Option Explicit`<br>`' to do`|Remove the module, or write what it is for.|
