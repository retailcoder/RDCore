# VBR00364: Object was unloaded

**Severity:** Error &nbsp;·&nbsp; **Family:** `VBR` (runtime semantics) &nbsp;·&nbsp;
**Source metadata:** [`VBRuntimeErrorInfo`](https://rubberduck-vba.github.io/RDCore.SDK/api/RDCore.SDK.Model.Errors.VBRuntimeErrorInfo.html)

A use of a Visual Basic 6.0 form loads it, and the form's `Form_Load` unloads it before the use is done.

Visual Basic run-time error 364; the numeric portion of the code is the error's number. A form that is not loaded is loaded by a use of one of its members or controls, or by `Load`, `Show` or `Hide`, and its `Form_Load` runs inside that use. When `Form_Load` unloads the form, the use fails, and the form is not loaded a second time to finish it (measured in VB6).

## How it is raised

|Situation|Example|Resolution|
|---|---|---|
|The form's `Form_Load` unloads it, under a use that loaded it.|`Form2.Show`, where `Form2`'s `Form_Load` runs `Unload Me`|Decide in the caller whether the form is to be shown, or hide the form in `Form_Load` instead of unloading it.|
